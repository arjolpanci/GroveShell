# ADR-008: Working codename only

## Status
Accepted

## Decision
"GroveShell" is used only as an internal development codename. It is not
treated as a cleared release trademark.

## Rationale
GNOME is a registered trademark of the GNOME Foundation, whose published
guidance says third parties should not modify or compound the GNOME word
mark or imply endorsement. Before any public release, the project must
either obtain written permission or rename to an independent mark, and
must never use the GNOME foot logo or imitate official GNOME branding. See
the "Important naming and legal note" at the top of `docs/PROJECT_PLAN.md`.
