# ADR-008: Working codename only

## Status
Superseded — GroveShell adopted as the project name (2026-07)

## Decision
Originally: treat the project name as an internal development codename only,
because the initial name compounded the GNOME word mark, which the GNOME
Foundation's trademark guidance doesn't permit.

The project has since been renamed to GroveShell, an independent mark with no
GNOME wording in it, which resolves the original concern. GroveShell is now
the project name, not a placeholder.

## What still applies
The underlying constraints that motivated this ADR remain in force:
- Never use the GNOME foot logo or imitate official GNOME branding.
- Never copy GNOME code or assets without independent license verification.
- Keep the independence disclaimer in the README: the project is not
  affiliated with, sponsored by, or endorsed by the GNOME Foundation.

See the "Naming note" at the top of `docs/PROJECT_PLAN.md`.
